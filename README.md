# analyst-agent

An analyst agent that remembers. Cleans messy real-world data in a persistent, sandboxed IPython kernel; answers questions over it; saves every verified fix as a tested, governed, reusable skill; and ships every answer with the code that produced it, the checks that passed, and the lineage from raw file to claim.

Status: P0 scaffold. Design docs live in `../mailo/coop-project/` (`analyst-agent-brief.md`, `analyst-agent-build-research.md`).
