# M1 exit report: the deterministic rung works

2026-09-04. Partial run (10 of 12 fresh cases; the run was stopped before
notes-truncation and tx-packed-fields refreshed). Batched arm
(`--policies auto`), telemetry live. Baseline preserved at
`bench/results/agent-baseline-pre-m1/`. Compared with `bench/compare.py`;
changed-nothing rows rescored to honest zeros.

## Headline

Where the autoclean rung applies (AUTO findings with a registered fixer),
the case goes from minutes to about two seconds at zero model calls, with
repair quality preserved where it is measurable:

| case | baseline | M1 | model calls |
|---|---|---|---|
| tx-dates-frozen | 143.5s, repair F1 1.00 | 2.1s, repair F1 1.00 | 0 |
| tx-header-damage | 220.7s | 2.2s | 0 |
| tx-constant-col | 87.6s | 1.5s | 0 |
| tx-sentinels | 400.0s | 54.7s | 1 |
| tx-suppression | 507.0s | 359.7s | 3 |

Mean wall-clock over the 6 cases scored in both arms: **298s to 112s, a 62%
cut**. tx-dates-frozen is the clean proof: identical perfect repair score,
70x faster, no model involved.

## First real cache measurement

Across the run's 12 model calls: 8,345 prompt tokens, **82.8% served from
cache** (6,912 hit / 1,433 miss). That lands right beside the field's
reported 85.8% (Deriv) and confirms the A0 cache work is paying before the
prompt-reorder surgery (A0 R5) even starts. Per-call model wait stayed
~103s, matching the baseline and the flash finding: M1 wins by removing
calls, not by speeding them up.

## What did not move, and why it is not a regression

Two GATE/model-path cases that scored 1.00 in the baseline came back
no_cleaned_output this run (tx-dates-mixed: the model failed to produce a
verified fix in 91s; tx-out-of-domain: chose clip-to-zero over sign-restore,
a defensible fix that misses the hidden truth). Both are GATE grade, so the
autoclean rung never touched them; the origin is "model" in both reports.
This is run-to-run model variance on the exact judgment calls a human gate
exists to adjudicate. It is the concrete argument for the A4 pass^k
consistency metric: single runs on model-path cases are noisy, and M1's
attributable wins are calls, wall-clock, and autoclean-path correctness,
all of which held.

## Exit gate verdict

- Calls per case on the deterministic path: down to 0 (target: down at least

- Repair/targeting on autoclean-path cases: not worse (dates-frozen held

- Person-grade gate count: unchanged; no person-grade auto-decided. Held.
