# A0 design: feel and visibility (WRAP)

2026-09-04. First phase of `specs/2026-09-04-agent-system-roadmap.md`.
Streaming coverage + cancel + steer, run telemetry, cache measurement.

## What the code already has (audited today, drives the scope)

- `llm.generate()` streams chunks behind a stall/call watchdog on a pump
  thread; drivers may render live (llm.py docstring says so).
- The QUERY path already emits model chunks as `StreamText("model", chunk)`
  with a heartbeat dot for reasoning-only chunks (loop.py:1600-1608), and the
  REPL renders StreamText live. Perceived dead air comes from the call sites
  that join chunks silently instead (loop.py:197, 600 and similar).
- `CRIVO_PROVIDER=openai` + `CRIVO_BASE_URL` already serve any
  OpenAI-compatible endpoint including Ollama (llm.py:144-165), and
  `CRIVO_MODEL` selects models on every provider. Model breadth is largely
  built at the seam; the adoption spec carries a status correction.
- A `faux` provider exists for tests: canned replies through the same
  watchdog path.

## Requirements

- R1 **Stream everywhere eyes wait.** Every `generate()` consumer either
  emits model chunks as `StreamText("model", ...)` or emits heartbeat dots
  when the output is intermediate machine text not meant for reading. No
  silent multi-minute joins. [touches loop.py: prepared as a proposal diff]
- R2 **Cancel one call, keep the turn.** A cancel signal (Ctrl-C in the REPL
  during a model call) aborts the in-flight generate() only: the watchdog's
  stop event is exposed as a cancel token; the turn resumes at the next
  event; completed work and the kernel are untouched. A canceled proposal is
  recorded in the transcript as canceled. [llm.py + repl: plumbing lane;
  loop handling: proposal diff]
- R3 **Steer at the next boundary.** During a stream the REPL accepts a typed
  note; it queues and is delivered as a user message at the next step
  boundary (before the next model call), never mid-kernel-exec. [repl:
  plumbing lane; loop consumption: proposal diff]
- R4 **Run telemetry.** New `crivo/telemetry.py`: JSONL span writer using the
  OTel GenAI semantic-convention attribute names; no OTel SDK dependency.
  Spans: model call (provider, model, latency, tokens in/out, cache hit/miss
  tokens), kernel exec (reuses transcript elapsed_s), gate (action, grade,
  decision latency), case/run roots sharing IDs with the transcript so /why
  can answer in time as well as lineage. Enabled by `CRIVO_TELEMETRY=path`;
  off by default; import-safe keyless. Streaming usage requires
  `stream_options={"include_usage": true}` on OpenAI-wire providers; the
  final chunk carries usage and DeepSeek returns
  `prompt_cache_hit_tokens` / `prompt_cache_miss_tokens` there.
  Bench rows additionally record `llm.model_info()`.
- R5 **Cache measurement first, prompt surgery second.** Telemetry reports
  cache-hit rate per run. Only after numbers exist: a proposal doc for
  prompts.py reordering (stable prefix: system, check definitions; volatile
  tail: schema, stats, findings; no timestamps early). Prompts are core, so
  the reorder ships as a reviewed proposal, not a silent edit.

## Acceptance

- REPL shows first visible model output within ~2s of a call starting on
  QUERY and CLEAN paths alike (heartbeats count as visible).
- Ctrl-C during a model call cancels that call; the session survives; a
  second Ctrl-C at rest still exits as today.
- A steer note typed during a stream appears to the model before its next
  call, verbatim, and the transcript records it.
- `CRIVO_TELEMETRY=...` produces JSONL that a schema test validates; a bench
  case run emits call spans whose cache fields sum to the usage totals.
- Keyless import paths unchanged (no telemetry, no network at import).
- Suite green; every new behavior lands test-first.

## Sizes and lanes

R2 llm.py cancel token + R4 telemetry + R5 measurement: Claude lane,
~2-3 days total. R1 + R3 loop-side consumption and the R5 prompt reorder:
proposal diffs for Aarmen's review (each small). Bench arm re-run after
landing to confirm no behavior drift.
